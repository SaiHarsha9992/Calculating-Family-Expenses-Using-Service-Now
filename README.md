# Calculating-Family-Expenses-Using-Service-Now

# Project Overview

Calculating-Family-Expenses-using-ServiceNow is a comprehensive application built on the ServiceNow platform designed to streamline the management and calculation of household financial expenditures.

This repository serves as a complete archive of the project's Software Development Life Cycle (SDLC). It contains everything from the initial ideation and empathy mapping to the final project report, including technical documentation, architectural diagrams, performance testing results, and video demonstrations of the working application.

# 📂 Repository Structure

This repository is organized into specific folders representing different phases and assets of the project. Below is a detailed breakdown of the contents:

# 📄 Documentation & Reports

Document/
Contains general project documentation files, including process workflows and the master project documentation.
Ideation Phase/
Documents the initial brainstorming sessions. Includes the Empathy Map Canvas, Problem Statement, and Idea Prioritization matrices.
Project Planning Phase/
Includes the PROJECT PLANNING PHASE.pdf which outlines the timeline, resources, and roadmap for the development.
Requirement Analysis/
Covers the technical requirements. Contains Data Flow Diagrams, User Stories, and the Technology Stack Architecture.
Project Design Phase/
Details the architectural and interface design of the application (PROJECT DESIGN PHASE.pdf).
Final Project Phase/
The culmination of the work, containing the FINAL PROJECT REPORT.pdf.

# 🛠️ Technical Assets & Testing

Project Files/
Holds core project assets and executable logic visualizers, such as images of JavaScript Business Rules and Relationship diagrams.
Performance Testing/
Contains the PERFORMANCE TESTING PHASE.pdf, detailing load testing, stress testing, and performance metrics of the ServiceNow instance.

# 🎥 Demos & Media

Project_Demo_Explanation/
Contains the primary walkthrough video (Project_Demo_Explanation (2).mp4) and its associated descriptive text.
Video Demo/
A collection of demonstration videos from individual team members showcasing specific features and functionalities of the Family Expenditure system.
